# Llama-3.1-8B dense-m 50题 Pilot 分析

## 1. 实验与审计范围

- 模型：`meta-llama/Llama-3.1-8B-Instruct`；
- 采样：temperature 0.6，top-p 0.9，max output 768；
- 任务：从旧500题中固定的50道 GSM8K；
- 拓扑：`n=5` 的 `m=4..16`，`n=8` 的 `m=7,10,...,49`；
- 每个非完全图分层5张图，完全图1张，共132张图；
- 每张图运行一次 clean 和全部非readout单点持续攻击；
- 不跨图、条件或运行复用生成结果；图内同轮广播仍只生成一次；
- 固定 `T=3`，启用因果活跃节点裁剪；
- 43,650 条 trace 全部完成，无失败或重试遗留；旧的 16k 输出上限失败批次未纳入。

节点机制审计成功配对 37,050 个 clean--attack 条件，覆盖 394,800 次正常节点更新，其中 readout 更新 111,150 次、内部节点更新 283,650 次。

置信区间采用10,000次 task bootstrap，条件于当前抽取的图。每个 `m` 的图间标准差单独报告，不能把 task 区间解释为整个合法图空间的不确定性。

## 3. 第一层判断

### 3.1 没有天花板效应

全部 clean 运行的 Round-0 平均准确率为81.4%，最终为85.7%，通信平均提升4.3个百分点。50题中只有10题在全部 Round-0 clean 采样中始终正确，1题始终错误，39题存在采样波动。因此这批题对 Llama 仍有区分度。

### 3.2 Utility 没有显示稳定的单调曲线

在 topology 层面，`m` 与 `UT` 的 Spearman 相关为：

- `n=5`: 0.198；
- `n=8`: 0.228。

相邻 `m` 的 task-bootstrap 对比中，没有任何 `UT` 差异的95%区间排除0。现有50题只支持“增加边后 utility 大致处于平台并伴随局部波动”，不支持单调提升、U形或唯一最优密度。

### 3.3 攻击条件准确率随密度上升，但攻击损失不呈同样关系

在 topology 层面，`m` 与 `Rmean` 的 Spearman 相关为0.479（`n=5`）和0.539（`n=8`）；与 `Rworst` 的相关为0.495和0.519。但 `m` 与配对攻击损失 `D=UT-Rmean` 的相关仅为 -0.200 和 -0.112。

因此不能把 `Rmean` 的上升直接解释为“目标攻击被抑制”。`Rmean` 同时受 clean 能力、普通错误、解析失败和目标错误影响。

### 3.4 当前没有清晰的 utility--robustness trade-off

`UT` 没有稳定下降，`Rmean` 反而总体上升，`D` 也没有随密度明显增加。当前 pilot 更接近“密度提高一般任务稳定性，但未明显减少目标攻击成功”，而不是一条清晰的 utility--robustness 交换曲线。

## 4. m=19 局部低谷的性质

`n=8` 中唯一由相邻 task-bootstrap 清楚区分的变化是：

- `m=16 -> 19`: `Rmean` 下降2.97 pp，95% CI `[-5.03,-0.91]`；
- `m=19 -> 22`: `Rmean` 上升4.29 pp，95% CI `[2.23,6.51]`。

但目标错误率在两次比较中基本没有变化：

- `m=16 -> 19`: +0.06 pp，CI `[-1.26,1.37]`；
- `m=19 -> 22`: +0.29 pp，CI `[-1.31,2.00]`。

低谷主要来自不可解析输出：1.89% -> 3.60% -> 1.66%，以及普通错误的局部增加。768-token 截断率在攻击条件下为0.91% -> 1.77% -> 0.74%。全体 trace 中，99.76%的 cap 输出最终不可解析；但只有44.53%的不可解析输出达到 cap，说明格式漂移也有贡献。

把不可解析运行排除后，`m=19` 的攻击准确率仍低于相邻分层，但低谷幅度明显缩小。因此它目前是“部分由生成/解析问题放大的局部异常”，不能当作稳健的拓扑安全低谷。

## 5. Exposure--adoption--recovery 机制

### 5.1 错误暴露随密度明显扩大

readout exposure：

- `n=5`: 39.9% (`m=4`) -> 92.0% (`m=16`)；
- `n=8`: 32.4% (`m=7`) -> 91.9% (`m=49`)。

内部节点也出现相同方向。这是结构可达性和固定三轮传播共同产生的结果。

### 5.2 条件采纳率总体下降，但不是严格单调

`P(C -> T | induced target exposed)`：

- 内部节点，`n=8`: 10.42% (`m=7`) -> 2.65% (`m=49`)；
- readout，`n=8`: 4.43% -> 2.11%；
- readout 在 `m=19` 局部升至6.11%，对应其输入中 target share 的异常回升。

`n=5` 在低密度区波动较大，从 `m>=10` 后 readout adoption 多数处于3%--5%。这说明“高密度 adoption 较低”是总体描述，不是每增加一条边都降低采纳率。

### 5.3 下降来自正确消息增长，而不是 target 消失

在已经暴露于 target 的 readout 更新中，平均 incoming target 数始终约为1.0--1.1；变化主要来自 incoming correct 数增加：

- `n=8,m=7`: mean C=1.15，mean T=1.00，target share=46.7%；
- `n=8,m=49`: mean C=5.53，mean T=1.09，target share=16.1%。

按 `(round,#C,#T,#O,#U)` 的 pooled transition law 仅重新加权输入组成，几乎复现 `n=8` 相邻密度的 adoption 变化；相邻残差绝对值不超过0.75个百分点。`n=5` 的低密度稀疏单元残差更大，暂不稳定。

这支持把 classical information mixing 视为当前最强的描述性候选机制，但 incoming composition 是 post-treatment 变量，现有结果不是因果中介证明，也不能据此声称发现了 LLM 特有机制。

### 5.4 Exposure 与 adoption 发生抵消

尽管条件采纳率下降，最终 target-error 比例没有同步下降：

- `n=5,m=4 -> 15`: 6.6% -> 7.1%，差值CI包含0；
- `n=8,m=7 -> 46`: 3.77% -> 4.80%，差值CI包含0。

与此同时，普通错误和不可解析输出显著减少，因此 `Rmean` 上升。换言之，高密度让 target 到达更多位置，但单次暴露更不容易被采纳，两种效应大致抵消；系统总体更准确，不等于对目标错误更安全。

## 6. 图间波动

同一 `m` 的经验图间标准差中位数为：

| n | UT SD | Rmean SD | D SD |
|---:|---:|---:|---:|
| 5 | 3.85 pp | 3.18 pp | 4.37 pp |
| 8 | 2.88 pp | 1.55 pp | 3.24 pp |

最大图间 range 达到：`n=5` 的 UT 14 pp、Rmean 10.5 pp、D 18.5 pp；`n=8` 分别为10 pp、6.57 pp、10 pp。边的排列可能重要，但当前每张图只有一个随机运行流，而且 Round-0 不复用，因此这些范围同时包含真实 topology 差异和随机生成噪声。需要在代表图上增加独立种子，才能分离两者。

## 7. 与上一轮结果的关系

上一轮4个 `m` 取点曾显示“中等密度更脆弱、最高密度回升”。本轮密集扫描说明：

1. 该形状不是平滑、普遍的 U 形曲线；
2. `n=8,m=19` 的局部低谷部分来自截断和解析失败；
3. 更稳定的机制趋势是 exposure 上升、target share 与 conditional adoption 下降；
4. 最终 target-error 并未随密度下降，旧结果中的 endpoint 回升主要不能解释为目标攻击被消除。

旧500题 reference 使用 temperature 0.3、共享 Round-0 和 state replay，本轮使用 temperature 0.6 且完全独立生成。因此同ID对照只能作为任务匹配参考，不能解释为单一模型或拓扑效应。

## 8. 当前可做与不可做的 claim

当前可以报告：

1. 该50题 pilot 对 Llama 不存在明显 utility 天花板；
2. 在当前图样本和固定 `T=3` 下，密度扩大 target exposure，但降低暴露后的条件采纳率；
3. 条件采纳率变化大部分可由接收消息中正确/目标错误的组成变化描述；
4. 攻击条件准确率随密度提高，主要伴随普通错误和解析失败减少，而不是最终目标错误减少；
5. 当前没有观察到清晰、稳定的 utility--robustness trade-off。

当前不能报告：

- 更密的图普遍更安全；
- 存在通用的中等密度鲁棒性低谷；
- information mixing 已因果解释所有 endpoint 变化；
- 观察到的机制是 LLM 特有、不同于经典传播模型；
- 五张图足以代表每个 `(n,m)` 的完整合法图空间。

## 9. 下一步无GPU分析

下一步应使用同一批 trace 和图，不新增模型调用：

1. 训练只读取 `(previous state, round,#C,#T,#O,#U)` 的 categorical transition baseline，并做 crossed graph--task holdout；
2. 在完全相同的初始状态、图和轮次上运行 DeGroot、比例阈值及多数更新基线；
3. 比较这些经典动力学对 final target rate、adoption 和 recovery 的解释残差；
4. 只有经典基线留下跨图、跨题稳定残差时，再设计语义内容干预。

这会直接服务于“分离图论结构 confound 与 LLM 语义更新”的研究目标。
