# 500 题完整 Pilot：固定 T=3 与实验 C

## 1. 为什么此前只有两个 m

此前报告只比较了 `n8_m10` 和 `n8_m21`，原因是当时实验 C 只对这两组结果进行了物理物化和审计，并不是完整实验只有两个边数。本报告统一纳入所有已经完成 500 道题的分层：

- `n=5`：`m=4, 8, 12, 16`；
- `n=8`：`m=7, 10, 14, 21`。

`n8_m28` 只有历史 100 题结果，500 题运行已取消，因此不纳入完整分析。`n5_m16` 在当前约束下只有一张唯一拓扑，不能用于估计同一边数下的图间变异。

实验 C 不需要重复调用模型。它将固定 `T=3` trace 严格截断到每张图的深度 `D(G)`，重新计算最终 readout 和传播指标。流式截断实现已与物理物化的 `n8_m21` 结果逐文件核对，`run_metrics`、`paired_attacks`、图指标和初始状态完全一致。

## 2. 分析范围与限制

- 数据：GSM8K 500 题；
- 模型：`meta-llama/Llama-3.1-8B-Instruct`，temperature 0.3；
- 每个非完全图分层选择 5 张图；
- 每张图包含一次 clean 条件和全部非 readout 单点持续攻击条件；
- 固定实验：所有图使用 `T=3`；
- 实验 C：每张图使用 `T=D(G)=max_v d(v,r)`；
- 区间：按 task 配对 bootstrap 10,000 次。

置信区间只反映题目抽样不确定性，仍然条件于当前选中的图、一个模型和一组实验种子。五张图不足以支持对整个随机图总体的普遍结论。

### 3.1 500 题中最稳定的新现象

第一，固定 `T=3` 时，内部目标错误传播随边数单调增加，而且相邻边数比较的 task-bootstrap 区间全部排除零：

- `n=5`：0.192 → 0.244 → 0.308 → 0.350；
- `n=8`：0.143 → 0.174 → 0.204 → 0.266。

第二，最终 readout 表现并不随传播范围单调恶化。两个节点规模均出现中间密度的鲁棒性低谷：

- `n=5`：攻击下降从 6.07 pp 上升到 8.30/8.70 pp，随后在 `m=16` 降至 4.95 pp；
- `n=8`：攻击下降从 3.31 pp 上升到 4.37/4.28 pp，随后在 `m=21` 降至 3.44 pp。

第三，内部污染与最终 readout 鲁棒性发生了解耦。最高密度条件中，目标错误到达更多正常节点，但 readout 的平均攻击后准确率反而高于中间密度条件。该现象在限定 clean 条件本来正确时仍存在：

- `n=5` 的 correct→any-error 比率：12.55%、14.48%、13.97%、9.49%；
- `n=8` 的 correct→any-error 比率：7.63%、8.67%、8.59%、6.99%。

这些结果支持“内部传播范围不能替代最终系统鲁棒性指标”，但尚不能证明高密度通过何种机制保护 readout。多条正确证据、重复错误被识别或后续纠错都只是待验证解释。

### 3.2 相邻密度的配对差异

固定 `T=3` 下较明确的变化包括：

- `n5_m8 - n5_m4`：攻击后准确率下降 1.19 pp，95% CI `[−2.06, −0.31]`；攻击损失增加 2.23 pp，`[0.97, 3.47]`；
- `n5_m12 - n5_m8`：攻击后准确率增加 0.96 pp，`[0.18, 1.75]`，但攻击损失变化不显著；
- `n5_m16 - n5_m12`：攻击后准确率增加 4.27 pp，`[2.85, 5.67]`；攻击损失减少 3.75 pp，`[−5.75, −1.78]`；
- `n8_m10 - n8_m7`：攻击后准确率下降 1.70 pp，`[−2.45, −0.95]`；攻击损失增加 1.06 pp，`[0.05, 2.09]`；
- `n8_m14 - n8_m10`：最终性能变化不显著；
- `n8_m21 - n8_m14`：clean utility 增加 1.24 pp，`[0.20, 2.32]`；攻击后准确率增加 2.08 pp，`[1.37, 2.83]`。

因此，当前数据不支持“边越多越安全”或“边越多越危险”的简单单调关系。

## 4. 实验 C 的完整结果

|---|---|---:|---:|---:|---:|---:|---:|

| n5_m8 | 2,2,3,3,2 | 85.68% | 78.08% | 7.60 pp | 65.68% | 8.12% | 0.173 |

| n5_m16 | 1 | 85.60% | 81.10% | 4.50 pp | 79.80% | 4.55% | 0.046 |
| n8_m7 | 3,3,3,2,2 | 87.48% | 84.26% | 3.22 pp | 77.60% | 3.93% | 0.132 |
| n8_m10 | 3,3,3,3,3 | 87.00% | 82.63% | 4.37 pp | 73.76% | 5.12% | 0.174 |
| n8_m14 | 3,3,3,3,3 | 86.84% | 82.56% | 4.28 pp | 71.64% | 4.94% | 0.204 |
| n8_m21 | 2,2,3,2,2 | 87.88% | 84.78% | 3.10 pp | 81.36% | 3.96% | 0.158 |

实验 C 下，密度与传播的关系明显改变：

- `n=5`：0.184 → 0.173 → 0.117 → 0.046；
- `n=8`：0.132 → 0.174 → 0.204 → 0.158。

这不能解释为稠密边本身抑制传播。稠密图通常更浅，实验 C 同时减少了正常更新轮次、持续攻击次数和可传播时间，因此它是一个拓扑相关的停止策略，而不是纯密度干预。

## 5. 实验 C 相对固定 T=3 的影响

较可靠的配对变化如下：

- `n5_m4`：攻击损失减少 0.38 pp，95% CI `[−0.75, −0.03]`；
- `n5_m8`：攻击损失减少 0.70 pp，`[−1.35, −0.04]`；
- `n5_m12`：clean utility 减少 1.48 pp，`[−2.40, −0.60]`，攻击损失减少 1.93 pp，`[−3.01, −0.87]`；
- `n5_m16`：攻击后准确率减少 1.95 pp，`[−3.70, −0.15]`；
- `n8_m10`、`n8_m14`：所有图深度均为 3，两种实验完全相同；
- `n8_m21`：目标错误率减少 0.77 pp，`[−1.03, −0.52]`，但最终准确率变化不显著。

`n5_m16` 是一个重要反例。实验 C 将 clean 正确条件下的目标错误翻转从 6.82% 降到 4.32%，但非目标错误翻转从 2.67% 上升到 6.43%，最终攻击后准确率反而降低。这说明：

> 目标攻击成功率下降不等于系统整体变得更可靠；缩短 horizon 既会截断恶意传播，也会删除正常纠错机会。

## 6. 100 题中看不清、500 题后才稳定的内容

历史 100 题运行使用旧版 runner，与 500 题版本在相同前 100 道题上的最终答案差异达到 15.7%–24.0%，因此不能直接把历史 100 与当前 500 当成纯样本量比较。这里使用当前 500 题 trace 的前 100 题子集重新计算。

最明显的变化发生在 `n5_m16`：

- 前 100 题攻击损失为 9.25 pp；
- 完整 500 题攻击损失为 4.95 pp。

只看 100 题时，完全图看起来与 `m=8/12` 一样脆弱；扩展到 500 题后，才显示其 endpoint 损失明显较低。其余变化为：

- `n=5`：`m4` 6.35→6.07 pp，`m8` 9.35→8.30 pp，`m12` 9.55→8.70 pp；
- `n=8`：`m7` 2.97→3.31 pp，`m10` 4.51→4.37 pp，`m14` 3.54→4.28 pp，`m21` 3.17→3.44 pp。

500 题还使以下判断更稳定：

1. 两个节点规模下，传播范围随固定 `T=3` 的边数单调增加；
2. endpoint 鲁棒性呈中间密度低谷，而不是简单单调变化；
3. 邻接密度之间的小幅差异可以通过配对区间区分，避免被前 100 题的难度构成主导；
4. 任务初始状态影响很大：当 Round 0 几乎无人正确时，攻击有时反而纠正 clean 错误，因此单一平均攻击损失混合了伤害与偶发有益扰动。

最后一点目前是探索性分层结果。稀有初始正确人数区间样本较少，不能单独形成强 claim。

## 8. 当前可支持的结论

目前可以较有把握地报告：

1. 在当前固定 `T=3` pilot 和所选图中，增加边数稳定扩大目标错误的内部传播范围；
2. 内部传播与最终 readout 损失并不单调对应，两个节点规模均出现中间密度鲁棒性低谷；
3. 只报告最终准确率会漏掉广泛的内部污染，只报告目标攻击成功率也会漏掉非目标错误；
4. `T=D(G)` 明显节省计算并减少攻击传播，但同时改变正常纠错机会和攻击暴露量，不应替代固定 horizon 的主实验；
5. 100 题足以发现粗略趋势，但不足以稳定估计部分密度条件，尤其会严重误判 `n5_m16`。

目前不能声称：

- 高密度图一般性地更鲁棒；
- 中间密度低谷是整个图空间的普遍规律；
- endpoint 与传播解耦由某个确定的 LLM 机制造成；
- 这些结果已经区别于经典传播模型。

这些 claim 需要更多图、其他模型/任务，以及按初始正确状态和消息级采纳过程进行机制分析。
