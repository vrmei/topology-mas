# Pilot：固定 T=3 与实验 C 的结果分析

## 1. 分析范围

- 数据集：GSM8K，500 道题。
- 模型：`meta-llama/Llama-3.1-8B-Instruct`，temperature 0.3。
- 拓扑：8 个节点（含 readout），每个边数条件 5 张图。
- 条件：每张图 500 次 clean 运行，以及 7 个非 readout 攻击位置各 500 次运行，共 4,000 条 trace；每个边数条件共 20,000 条 trace。
- 原始实验：所有图固定运行到 `T=3`，同时启用 active-node pruning。
- 实验 C：令有效 horizon 等于图深度 `D(G)=max_v d(v,r)`；恶意节点在有效 horizon 内持续注入固定目标错误。
- 不确定性：按 task 聚类的 10,000 次配对 percentile bootstrap。置信区间只反映 500 道题的抽样波动，仍然条件于当前选中的 5 张图、单一模型和单一种子。

实验 C 不是逐攻击位置令 `T=d(a,r)`。它保证最远节点至少有一次信息能够到达 readout，但距离更近的攻击节点仍可能重复注入。因此它减少了攻击剂量差异，却没有完全消除剂量差异。

## 2. 原始固定 T=3 实验

| 指标 | m=10 | m=21 | m=21 − m=10（95% CI） |
|---|---:|---:|---:|
| Clean accuracy | 87.00% | 88.08% | +1.08 pp [0.12, 2.08] |
| Mean attack accuracy | 82.63% | 84.64% | +2.01 pp [1.25, 2.76] |
| Mean paired accuracy drop | 4.37% | 3.44% | −0.93 pp [−1.86, 0.01] |
| Induced target-error rate | 5.12% | 4.73% | −0.39 pp [−0.83, 0.05] |
| 最大诱导非攻击节点数（均值） | 0.174 | 0.266 | +0.092 [0.077, 0.108] |

当前样本中，`m=21` 的最终 clean accuracy 和平均攻击后准确率均高于 `m=10`。但更密集的图同时扩大了目标错误在内部节点中的传播范围。也就是说，**最终 readout 正确率与系统内部污染范围并不等价**：一个图可以保留更好的最终输出，同时让错误到达更多内部节点。

这只能作为 pilot 现象。`m=10` 和 `m=21` 各只有 5 张图，task bootstrap 没有纳入图采样不确定性，尚不能声称增加边数一般性地提高鲁棒性或扩大传播。

逐图描述中，5 张 `m=10` 图的最坏节点攻击准确率均值为 73.76%，5 张 `m=21` 图为 81.44%；但 `m=10` 中一张图的最坏值仅为 58.6%，对均值影响很大，因此该差异暂不作推断性解释。

## 3. 实验 C 的复用与审计

- 5 张 `m=10` 图的深度均为 3，因此实验 C 与原始 `T=3` 完全相同，20,000 条 trace 可直接复用。
- 5 张 `m=21` 图中，4 张深度为 2，1 张深度为 3。
- 对 `m=21` 的 20,000 条实验 C trace 进行了逐条审计：
  - 16,000 条 depth-2 trace 被截断到 Round 2；
  - 4,000 条 depth-3 trace 保持 Round 3；
  - 每个保留 turn 的 prompt、generation seed、raw output、parsed answer 和 answer state 都与原始 trace 前缀完全一致；
  - 最终 readout 等于原始 trace 在截断轮次的 readout；
  - 审计无 mismatch。

因此，实验 C 的结果不是重新采样导致的变化，而是对同一随机实现进行严格的前缀截断。

## 4. 实验 C 与固定 T=3 的严格配对比较

以下只使用 4 张 depth-2 的 `m=21` 图；depth-3 图作为零差异控制。

| 指标 | C − 固定 T=3（95% CI） | 解释 |
|---|---:|---|
| Clean accuracy | −0.25 pp [−0.95, 0.45] | 未观察到稳定净变化 |
| Mean attack accuracy | +0.17 pp [−0.27, 0.61] | 未观察到稳定净变化 |
| Mean paired accuracy drop | −0.42 pp [−1.21, 0.35] | 未观察到稳定净变化 |
| Induced target-error rate | −0.96 pp [−1.29, −0.64] | 目标错误到达 readout 的比例下降 |
| 最大诱导非攻击节点数 | −0.135 [−0.150, −0.122] | 内部传播范围明显缩小 |
| Clean logical calls | −8.0 / run | 少一个 round 带来显著节省 |
| Attack logical calls | −7.0 / run | 少一个 round 带来显著节省 |

四张 depth-2 图的 induced target-error rate 均下降，幅度为 0.69–1.23 pp；但 mean attack accuracy 两升两降。说明删除 Round 3 最稳定的作用是减少目标错误继续扩散，而不是一致地提高最终正确率。

Round 2 与 Round 3 的配对转移也支持这一解释：

- clean：2,000 个 graph-task cell 中有 53 个（2.65%）改变正确性；Round 3 纠正 29 个，也破坏 24 个，净收益仅 5 个 cell。
- attack：14,000 个 graph-task-attack cell 中有 682 个（4.87%）改变正确性；Round 3 纠正 329 个，也破坏 353 个，净变化反而略偏负。

因此目前有把握的描述是：**额外一轮会改变一小部分最终决策，但在当前 pilot 中没有显示稳定的净准确率收益；它更明确地增加了攻击目标的传播机会。** 这不是“多轮必然有害”的一般结论。

## 5. 脆弱节点排序是否改变

在 4 张 depth-2 图中，固定 `T=3` 与实验 C 的节点脆弱性排序 Spearman 相关为 0.82–0.98；其中 3 张图的最坏攻击节点不变，1 张图发生改变。

这表明本 pilot 中截断一轮没有彻底重排结构性脆弱位置，但证据仅来自 4 张图。该结果更适合作为后续扩大图数量时需要复核的稳定性指标，而不是当前主结论。

## 6. 计算量

| 条件 | Logical calls | Input tokens | Output tokens |
|---|---:|---:|---:|
| 固定 T=3, m=10 | 175,500 | 133,687,811 | 41,765,871 |
| 固定 T=3, m=21 | 245,500 | 242,049,882 | 58,385,792 |
| 实验 C, m=21 | 131,500 | 127,511,020 | 31,128,235 |

相对固定 `T=3, m=21`，实验 C 的 logical calls 减少 46.4%，input tokens 减少 47.3%，output tokens 减少 46.7%。本次 C 运行的 backend calls 为 0，是因为全部状态都能从原始实验前缀复用；这不代表从头运行实验 C 不需要模型推理。评估未来成本时应使用 logical calls 和 token 量，而不是本次复用后的 backend calls。

固定 `T=3` 时，`m=21` 相对 `m=10` 每个 clean run 多 4 次 logical call、每个 attack run 平均多 3.43 次，并显著增加输入 token。原因不只是边传输本身，而是更多边缩短节点到 readout 的距离，使 active-node pruning 下更多节点在后续轮次仍处于有效因果范围，同时每次更新读取更多邻居消息。

实验 C 下不能直接用 `m=21` 与 `m=10` 推断边密度效应：本批 `m=10` 图深度均为 3，而 4/5 的 `m=21` 图深度为 2。此时边数、图深度、运行轮数、正常推理量和攻击暴露量同时变化。

## 7. 当前可支持的结论

1. 在本 pilot 的固定 `T=3` 设置中，选中的 `m=21` 图拥有更高的 clean 和平均攻击后准确率，但也出现更广的内部目标错误传播。
2. 对 depth-2 图删除多余的 Round 3，几乎不改变平均最终准确率，却显著减少目标错误到达 readout 和其他正常节点的机会，并减少约一半逻辑计算量。
3. 最终正确率不足以单独刻画鲁棒性；至少还应同时报告目标错误采纳率和内部传播范围。
4. 实验 C 是有价值的效率与 horizon 敏感性分析，但不应替代固定 horizon 主实验，因为它把拓扑深度与推理预算、正常纠错机会和持续攻击剂量绑定在一起。

## 8. 下一步

优先使用现有 trace 做无需 GPU 的分层分析：按攻击节点到 readout 的距离、路径冗余和支配关系，分别比较固定 `T=3` 与实验 C 的攻击损失及目标错误采纳。该分析可以判断 C 的传播下降主要来自少一次持续注入，还是来自特定结构位置被提前截断。

在扩大正式实验时，建议保留两条报告线：

- 主结果：固定 horizon，用于同等交互机会下比较不同拓扑。
- 敏感性结果：`T=D(G)`，用于衡量部署时按图深度停止所获得的成本收益与传播变化。

不要把实验 C 下不同边数条件的直接差异解释为纯拓扑密度效应。
